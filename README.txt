THE WINNING CIRCLE — PUBLISHING-READY WEBSITE

This version includes:
• Story categories
• Individual story pages
• Search by title/author/excerpt
• Category filtering
• Author/date information
• Social-media button placeholders
• Newsletter signup UI
• Responsive mobile design
• A central stories.js file that acts as the story catalogue

IMPORTANT:
This package is publishing-ready on the FRONT END. To make it a true
no-code publishing system where you can log in and add stories without
editing files, connect the site to a CMS such as Decap CMS, WordPress,
or another headless CMS.

For a simple next step, replace the # social links in the HTML with your
real Instagram, YouTube and TikTok URLs.

To preview:
Open index.html in your browser.

To publish:
Upload the folder to GitHub Pages, Netlify, or Cloudflare Pages.

The included sample stories are placeholders and can be replaced with your
own stories.
